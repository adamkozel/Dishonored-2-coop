# Native Domino / PhantasmalLink investigation

## Scope and evidence levels

This investigation follows the preserved Mesmerize airborne continuity work. Domino has its own native state and target-link behavior; it is not assumed to follow the Mesmerize three-asset scheme. The original Steam resources are read-only. The new finite fixture is restricted to the exact isolated Emily/Dunwall context; normal controller input alone uses the power. It does not invoke target linking, target damage, or cosmetic receiver gameplay functions.

## Confirmed installed assets

The first `domino` search finds upgrade declarations, sound events and UI resources. The upgrade's `ARK_ATTRIBUTE_PHANTASMAL_LINK_EXTRA_NODES` name identifies the internal power terminology. [Void export manifest](../../outputs/d2-coop-lab/research/asset-exports/phantasmal-native-v174/manifest.json) contains exact paths and hashes:

- `models/powers/phantasmallink/phantasmal_link.inventoryitem`: type POWER, Emily journal header, equipment `models/powers/phantasmallink/phantasmal_link.def`.
- `components/characters/player/base/powers/phantasmallink/phantasmal_link.cpntpowerphantasmallink`: Emily usage, quick-use `PLAYER_STATE_USE_PHANTASMAL_LINK`, ordinary and sliding cast scenes, target tag `possession_target`, network entity `models/powers/phantasmallink/phantasmal_network.def`, targeting effect `models/effects/gameplay/powers/phantasmal_link/target/phlink_targeted_01.fx`.
- `midnight/gameplay/player/base/powers/power_phantasmal_cast.midnightscene`: native groups PlayerLeftArm and PlayerBody; six subscenes `Cast_In`, `Cast_Loop`, `Cast_Select_out`, `Cast_final_Select`, `Cast_Select`, `Cast_fire`.
- A separate `power_phantasmal_cast_slide.midnightscene` exists. Its presence is not runtime slide coverage.

The base component declares swimming usability, 0.25-second cooldown, mana cost40 and replenish20. The subsequently exported equipment entity contains an authored inline component overriding mana cost to **25**. Reading only the base component would therefore give the wrong effective configuration. Neither declaration value alone proves the outcome of a particular cast.
