The [indexed API transcript](../../work/natural-moveset/native-interaction-families-v827/ghidra-usable-indexed-api-v829.json) records decompilation, cross-references and exact bytes. `14077b920` accepts component, integer target index and byte force. With force0 it validates the index, treats an already-current request as a no-op, queues an opposite request at component+0x2c while the transition flag is set, otherwise delegates to `14077a880` with native transition/notification behavior. It marks the owner for update via+0xd4 bit4. The exact32-byte prefix is checked before every call. Force1 is not used.

`14077b870` requests a state by name using the entry's first pointer. These windows have empty state-name strings, so the indexed API avoids inventing names. Xrefs to the indexed entry include140497fe3 and14049802b; an attempted caller lookup returned no defined function. No caller behavior is inferred from those addresses alone. Ghidra bookmark `D2Coop_UsableIndexedApi_830` at14077b920 is saved in the persistent exact-executable project.

`14077ae00`, the ordinary-use event path, carries an instigator and calls an additional native system before cycling. The chosen indexed state setter preserves native state, animation, update and state/script notification machinery, but this does **not** establish equivalent AI awareness or quest instigator semantics. Those effects need their own authority work before widening eligibility. The ordinary cycle refuses input during its transition; indexed requests can queue it. Network replication therefore carries a desired index rather than replaying a use/toggle event.
