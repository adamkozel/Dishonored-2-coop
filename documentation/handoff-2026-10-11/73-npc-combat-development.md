## Initial implementation850–852

[npc_combat_protocol.h](../../outputs/d2-coop-lab/src/npc_combat_protocol.h) defines a220-byte reliable event envelope with native NPC binding, both process sessions, world epochs, map, actor arms, handles and rig identity, plus a separate combat nonce. Client Request messages carry hit geometry and an ordered request ID, never prescribed health. Only host Commit messages can carry before/after/max health and native inflicted damage.

[npc_combat.h](../../outputs/d2-coop-lab/src/npc_combat.h) requires explicit opt-in by both test roles after NPC authority negotiation. A normal client sword contact returns the native empty damage result locally and queues a request. The host reconstructs the native hit with the locally owned partner as attacker, obtains the native result and orders a commit. The client applies the matching native result once, preserving source attribution. Both local-host and client-source callbacks are captured into a bounded queue. Candidate865 reconstructs fresh native parameters on the engine thread before entering the ordered commit stream; original callback blocks are never replayed. Per-actor request and outcome counters reject duplicates and gaps.

The existing friendly-fire, clone-animation and carried-presentation filters execute before the combat hook. An explicitly validated authoritative replay calls the original native entry; animation events still take the ordinary filtered path. No network pointer, direct health write, original Steam asset replacement or new game UI is introduced.

Initial scope is repeated **nonfatal ordinary sword** damage. Health maxima are not hardcoded to40, but no broader runtime coverage follows from that fact. Fatal hits, other declarations, queued native damage, unsupported native geometry and invalid sessions stop this experimental adapter. Pending client requests are limited to one per actor. Menus/reloads retire the combat experiment; automatic combat recovery and general death ownership remain outstanding. These are limitations to remove before making this the default gameplay path.
