D2Coop 0.1.0 (beta) - co-op for Dishonored 2 (Steam version only)

Install: copy dinput8.dll and D2Coop.ini into the game folder (next to Dishonored2.exe).
Uninstall: delete dinput8.dll from the game folder.

Playing together: both players in one virtual network (Radmin VPN or Hamachi).
F7 opens the network panel: nickname, language, lobby.
Host: "Create lobby", give the partner your Radmin VPN / Hamachi address from the panel.
Partner: enter the host's address, "Connect".
The host's world comes to the partner by itself: the host picks a save or a mission, the partner loads after.

Bugs: send D2Coop.log from the game folder (from both PCs) with a description of what happened.

D2Coop 0.1.0 (бета) — кооператив для Dishonored 2 (только Steam-версия)

Установка: скопировать dinput8.dll и D2Coop.ini в папку игры (где Dishonored2.exe).
Удаление: удалить dinput8.dll из папки игры.

Игра вдвоём: оба в одной виртуальной сети (Radmin VPN или Hamachi).
F7 — сетевая панель: ник, язык, лобби.
Хост: «Создать лобби», напарнику — свой адрес Radmin VPN / Hamachi из панели.
Напарник: ввести адрес хоста, «Подключиться».
Мир хоста приходит напарнику сам: хост выбирает сохранение или миссию, напарник загружается вслед.

Ошибки: присылать D2Coop.log из папки игры (с обоих ПК) и описание, что произошло.
